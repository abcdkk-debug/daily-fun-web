🤔 點解機場咁多的士？

樟宜機場 2 公里內有 421 架得閒的士，佔全島 14.6%，3 公里內更加有 513 架。機場有的士站排隊上客，司機鍾意喺嗰頭等 — 朝早 7 點第一批航班陸續到埗，需求大，供應自然集中。最密嗰一格（北緯約 1.36°、東經約 103.99°）就有 216 架，應該就係機場的士站同附近路段。

相反，聖淘沙 2 公里內得 3 架 — 島上面積細、路少，遊客多數搭輕軌或者纜車，的士唔會專登入去等客。市中心嘅濱海灣（31 架）同烏節路（39 架）星期六朝早都唔算多，商場未開、夜生活又完咗，司機都去咗住宅區等返工返學嘅人：義順 183 架、兀蘭 179 架、淡濱尼 170 架。

留意：呢個 API 只計「得閒等客」嘅的士，唔包括已經載客或者「唔得閒」嘅車；數字每分鐘都喺度變，撳上面「重新讀取」可以睇最新數。

📊 數據來源：Taxi Availability（的士供應）即時 API — 新加坡陸路交通管理局（LTA），經 data.gov.sg 發佈（api.data.gov.sg/v1/transport/taxi-availability，免金鑰、無需登記；新加坡開放數據授權 Singapore Open Data Licence v1.0）。回應係 GeoJSON MultiPoint，每個點係一架目前得閒可供租用嘅的士嘅經緯度，唔包括已載客或忙碌中嘅的士。

🕒 查核快照：2026-11-28 07:03 HKT（香港時間；新加坡同香港同一時區）讀到嘅數據；即時讀取失敗時會顯示呢份快照。快照數字：全島得閒的士 2,891 架；樟宜機場 2 公里內 421 架（佔 14.6%）、3 公里內 513 架；聖淘沙 2 公里內 3 架；最密一格 216 架。
