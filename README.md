# 🌍 Daily Fun Web — 每日開放數據趣聞網頁

每日一期，用世界各地**開放數據平台**（open data platforms）的真實數據，整一版有趣網頁：排行榜、互動圖表、冷知識同小測驗。

重點係整**會用到呢啲數據的網頁**：揀真實數據集，將數據本身放入頁面入面用 — 即時讀取官方 API，或者嵌入已核實的數據集快照，再用圖表、排序、篩選等方式呈現同探索。
