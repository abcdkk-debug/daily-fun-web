📌 數據來源

數據集：運輸署「停車場資訊及空置車位」即時數據，經 DATA.GOV.HK（香港政府一站通開放數據平台）發布。
API：https://api.data.gov.hk/v1/carpark-info-vacancy?data=info 及 ?data=vacancy（免金鑰，繁體中文）。
查核快照：2026-11-16 09:13 HKT — 當時 589 個停車場、555 個有即時私家車空位數字、空位總數 20,284 個、38 間爆滿。頁面載入時會先即時讀取最新數據，讀唔到先用呢個快照。
備註：API 本身將啟德 AIRSIDE 停車場以兩個編號重複列出，上面總數係按 API 公布數字直接加總；個別停車場未提供即時空位數字，會顯示「未提供」。
