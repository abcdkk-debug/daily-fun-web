# 夢境宇宙 DREAMVERSE — 天馬行空實驗室

一個沒有限制的宇宙沙盒 Web App：

- **宇宙沙盒**：撳一下爆星塵、拖曳彈射行星、雙擊開黑洞，仲有大爆炸、流星雨、反重力、蟲洞跳躍
- **物理自己話事**：重力（可負數）、時間流速、星塵數量全部即時調
- **平行宇宙產生器**：一掣擲出一個新宇宙 — 物理定律、居民、貨幣、天氣、危險度全部隨機
- **荒誕發明機**：三樣唔關事嘅嘢夾埋，轉出改變世界嘅發明
- **如果……？**：每日都唸唔完嘅天馬行空問題

純前端單檔 `index.html`，唔使登入、唔收集資料，喺瀏覽器即時計物理。
